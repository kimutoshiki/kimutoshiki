# Four atlas walls

The four maps supplied by the owner are preserved at their original 1672 × 941
pixel dimensions. No cropping, stretching, generated replacement, or metadata
is introduced. Each map is encoded as WebP quality 96 with method 6.

| File | Wall viewed from the desk | Bytes |
| --- | --- | ---: |
| `karatsu.webp` | Front | 777026 |
| `world.webp` | Right | 438662 |
| `japan.webp` | Back | 388364 |
| `europe.webp` | Left | 495642 |

The physical panels use the original 1672:941 aspect ratio with the full 0–1 UV
range. They receive the room's sunlight and shadows. Only Karatsu loads during
initial preparation; other maps load when their wall enters the camera view.
