# 2026年9月9日の修正内容

対象：kimutoshiki.com（GitHub：kimutoshiki/kimutoshiki）

画像生成で作成した３枚の素材画像から、９種類の質感をサイト用に組み込みました。

| 対象 | 修正内容 |
|---|---|
| 机・棚・木製パネル・模型の台 | 木目画像を使ったウォールナットの質感 |
| 大隈講堂・唐津城・旧唐津銀行・像の台座 | 石材・しっくい・れんが・屋根材の質感 |
| 観葉植物 | 曲面の葉に葉脈画像を適用し、緑色の濃淡を調整 |
| 猫 | 体・尾・足の毛並み画像を適用。顔の模様、目・鼻・耳・ひげは既存の形状を使用 |
| 椅子のクッション・掛け布 | 臙脂色の織物の質感 |
| 詳細ページ・写真の額縁・フッター | 3D空間と共通の木目・壁面・布地を使用し、色調と読みやすさを調整 |

追加画像の通信量は合計705,040バイトです。画像を読み込む間は既存の素材を表示し、読み込みに失敗しても建物などが消えないようにしています。葉や猫の動き、上下左右からの鑑賞、0.65～6倍のズーム、写真・文章・ページ移動を引き継いでいます。

建物の表面に画像を貼ると、一部の描画方式で時計の画像と誤認される不具合も修正しました。箱形の建材には大きさに応じた画像の座標を設定し、極端な引き伸ばしを抑えています。

確認済み：130フレームの実際の3Dシーン・操作検証、時計台４面の不透明表示、部屋の壁と天井、各対象の形状数、６方向の視点、ズーム、タッチ操作、縦画面での倍率保持、画像の正常読み込み・失敗・遅延読み込み、描画した画素の検証、ページ内145件のローカル参照先。

ブラウザのスクリーンショットによる確認や、実機ごとのGPU表示確認は実施していません。画像生成機能にはモデルの版を選ぶ設定がないため、「2.5」を指定したという確認はできません。

元の形状を生かした質感の更新です。新たに実測した建物モデルや、測定済みの物理素材データではありません。生成に用いた全文の指示と実装上の注意は `generated-materials.md` に記録しています。
